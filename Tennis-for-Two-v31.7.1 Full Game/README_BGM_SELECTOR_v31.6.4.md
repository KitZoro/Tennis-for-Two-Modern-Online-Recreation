# v31.6.4 — Main-Menu BGM Selector

The main menu now includes **9 — CHOOSE BGM**.

## Controls

- Up/Down: highlight a track
- Enter: select and immediately preview the track
- R or F5: rescan the `music/` folder
- M: mute/unmute music
- Esc: return to the main menu

The list always includes the built-in synth and automatically includes every
`.mp3`, `.ogg`, and `.wav` in `music/`. The selected filename and volume are
saved in `~/.config/tennis_for_two/audio_settings.json`.

External music loops continuously in Story Mode and every match type.
