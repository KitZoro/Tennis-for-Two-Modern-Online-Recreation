# Tennis for Two v31.1 — 2D Edwin Story

This build deliberately returns to the clean v31 Fast Input Network base.

## What changed
- Story Mode draws Edwin Skycross directly in Pygame as a grey rabbit.
- Long rabbit ears, black ear tips, white muzzle, purple eyes, and a simple jacket are part of the code.
- EDWIN / VOICE / SYSTEM each get their own story portrait treatment.
- Existing Tennis for Two local, CPU, online, network-test, audio, rollback, and fast-input code is left intact.
- No Blender, Panda3D, FBX conversion, or external character assets are required to play Story Mode.

## Run
```bash
chmod +x run_linux.sh
./run_linux.sh
```

The player/distribution build can be made separately later.
