# Tennis Bot Pack

This pack has both kinds of Tennis Bot.

## In-game bot

Use:

`in_game/v30_tennis_bot_arena_PATCH.py`

It adds **TENNIS BOT — ADAPTIVE** to Tennis for Two. It learns the player's
positioning during the match and chooses angle/power to attack open court.

It also contains reusable Story Mode profiles:

- `rally`
- `adaptive`
- `aggressive`
- `boss`

The patch does not change TCP/TLS, rollback, protocol 29, or online play.
